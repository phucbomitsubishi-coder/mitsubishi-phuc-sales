# Ảnh phụ kiện cho video `npm run video -- phu-kien <xe>`

Đặt ảnh theo tên gợi ý, ví dụ `triton/nap-thung.jpg`. Ảnh trong `chung/` dùng cho mọi xe (khi xe không có ảnh riêng).
Ảnh dọc hoặc ngang đều được (cảnh tự cắt giữa ảnh), nên rộng 1080–1600px, dưới 400 KB.

Tên gợi ý:
- Triton: `nap-thung`, `thanh-the-thao`, `ty-bung-thung`
- Mọi xe: `phim-cach-nhiet`, `camera-hanh-trinh`, `lot-san`, `phu-gam`, `cam-bien-ap-suat-lop`

Chạy video xong, tool in ra các file ảnh còn thiếu. Chỉ dùng ảnh tự chụp hoặc ảnh được phép dùng.
